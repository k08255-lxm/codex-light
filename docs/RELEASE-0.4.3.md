# v0.4.3

## 新增
- 扫码连接：在电脑的“远程控制 → 局域网访问”生成二维码，手机扫描即可配对。二维码两分钟有效、仅可使用一次。
- 自动检查更新：电脑启动后和使用期间检查新版本；新版 Android 客户端在进入前台时检查，有更新会提醒。
- 欢迎页按本机时段轮换问候，文字不会随着界面刷新反复跳变。

## 改进
- “DSH 与 MCP”独立成设置页，不再与“连接与运行”显示同一内容。
- 手机的目录入口移至右上角，桌面保持原位置。
- 统一 Codex 配置页排版，修改确认只在需要时出现。
- 重新整理关闭提示，避免按钮文字截断，区分退出与转入托盘。

## 更新提醒
- Android 0.4.2 没有自动检查功能：请先手动下载本页 APK，直接覆盖安装。无需卸载，也不要清除应用数据；从 0.4.3 起会提示后续更新。
- 电脑和手机版本均为 0.4.3。局域网网页访问仍可使用，不强制安装 APK。
- 配对仍使用可信局域网内的 HTTP，请勿在公共网络或公网暴露服务。更新不会自动安装，需要你确认。
