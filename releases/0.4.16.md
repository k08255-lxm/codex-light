码舱更新了浅色和深色外观，新增 DSH 配色，展开和收起历史操作时也能留在正在阅读的位置。

## 对话与任务

- 对话轮次和操作详情可以平滑展开、收起。阅读历史时收到新输出会保持当前位置，点击「回到底部」即可重新跟随。快速切换对话时直接显示内容，读取较慢时标题旁才会出现进度指示。
- 可以把文件和图片直接拖进聊天窗口。逐行有效的 JSONL、NDJSON 文件会识别为文本附件。
- 手动停止正在运行的任务时，待发送消息会留在队列里，等你决定是否继续。
- 右击项目或点击省略号可打开同一菜单，菜单宽度随内容调整。「在资源管理器中打开」支持 Windows 和 WSL 项目目录。
- 普通「新对话」会沿用上一次选择的项目，也会记住「无项目」。从指定项目发起新对话时，使用该项目。
- DSH 桥已适配 DeepSeekHarness 0.2.3-alpha.2，支持创建、保存和恢复子会话。使用 0.2.3-alpha.1 的 npm CLI 时，连接提示会说明该版的依赖问题。

## 桌面与设置

- Codex 风格重新调整了输入框、侧栏、消息、代码和终端的配色。新增的 DSH 浅色和深色风格使用细灰线标出正在输入的对话框。
- 打开应用即可在聊天首页查看当前账号的剩余额度，首次读取失败会自动重试。
- 在「设置 → 连接与运行 → 窗口与后台服务」可分别开启「任务运行时阻止休眠」和「远控连接时阻止休眠」。两项默认关闭，屏幕仍按系统设置熄灭。

## 手机端

- 电脑更新后，手机重新连接即可用上新的滚动行为。向上翻看历史时，新输出会保留当前阅读位置，点「回到底部」可恢复跟随。

## 安装与更新

- Windows 可在应用内检查更新，首次安装请下载 [Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.16/CodexLight-Setup-0.4.16-x64.exe)。
- 手机可沿用现有 Android 客户端。首次安装请下载 `codex-light-android-0.4.16.apk`。
