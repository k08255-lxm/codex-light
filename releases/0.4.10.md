这次更新让你可以直接开始无项目对话，也更容易找到需要回答的问题、读完子代理的工作记录。

## 对话与任务

- 可以直接新建无项目对话，也可以在项目内继续工作。查看历史会话时列表保持原位，发送新消息才更新最近活动顺序。
- 右击侧栏会话可以重命名、生成摘要标题、归档或删除。中断任务后继续聊天，已发送的消息会留在原来的轮次。
- 子代理按任务分段显示。查看详情时可以向上翻看早先的工作，新的输出会保留阅读位置。代码、命令和文件差异更容易辨认。
- 点击上下文百分比可查看已用和剩余容量，以及引擎提供的输入、缓存、输出和推理用量。用量统计新增按本地日期计算的「今天」。
- 修正有完整 diff 却显示「行数未知」的情况。展开的文件变更浮窗会对齐对话区，阅读详细改动时可保持滚动位置。
- 运行提示的渐变只扫过文字。任务结束或停止后，项目列表里的会话名恢复静止。

## 桌面与设置

- 模型提问和审批可以发送系统通知。任务栏数字角标汇总待回答问题和未读完成轮次，有问题等你回答时会闪烁提醒。
- 在「设置 → 配置」可以直接保存常用设置、调整新会话的并发线程上限，或用「立即测试」验证标题模型。批准方式会在同一会话的电脑与手机之间同步。
- Windows 支持自动选择引擎，或指定全局 npm CLI、官方客户端内建引擎。可以为 npm 开启自动检查，在下次启动前安装更新。官方内建引擎随官方客户端更新。

## 手机端

- 手机连接、权限和更新集中到同一个设置入口。查看子代理详情时，系统返回手势先回到子代理列表。
- 可在手机通知设置开启后台同步，接收电脑上的任务进度、提问和审批提醒。支持 Android 实时通知的设备会显示系统是否已提升这条通知。
- 可以自动或手动检查手机版更新。有新版时，点顶栏应用名与额度之间的更新按钮，即可查看下载进度并确认安装。

## 安装与更新

- Windows 安装包为 `CodexLight-Setup-0.4.10-x64.exe`。桌面端会自动检查更新，并在下载安装包、打开安装器和更新结束时显示状态。
- Android 安装包为 `codex-light-0.4.10.apk`。从旧版手机应用进入发布页下载并安装一次，即可使用新版应用内更新。
