Windows 版码舱重启后会恢复已开启的公网访问，已配对的手机可以直接重连。

## 对话与任务

- 桌面打开长对话时，先显示最新回复，再自动补齐全部时间线刻度。无需向上滚动，便可点刻度跳到最早的一轮。

## 桌面与设置

- 公网地址、本机端口和连接方式会随配置保存。使用自建服务器时，码舱也会重新连接上次启用的 SSH 中继。
- 手动关闭公网入口会取消自动恢复并撤销公网配对。只断开 SSH 中继会保留手机配对。

## 安装与更新

- v0.4.25 及更早版本的公网配对会在退出时失效。首次升级到这版后，请重新开启公网入口并配对一次。
- Windows 支持应用内更新。首次安装请下载 [Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.26/CodexLight-Setup-0.4.26-x64.exe)。已安装的手机无需更新，首次安装可下载 [Android APK](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.26/codex-light-android-0.4.26.apk)。
