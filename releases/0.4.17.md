原先配对的手机现在可以等电脑自动恢复远控，并在通知栏跟踪任务进度。

## 对话与任务

- 桌面端与本地服务重连时，左下角会显示进度，恢复后切回已连接。对话中不会再残留旧的断线提示。

## 桌面与设置

- Codex 暗色风格改用更深的灰色，标题栏、侧栏、聊天区和输入框采用一致的色调。
- 移除了独立的终端与 Git 工作台，以及侧栏、菜单和斜杠命令中的入口。
- 开启并保存局域网访问后，电脑启动或网络短暂中断时会在后台重试。原可信网络、地址和端口可用后即可重新连接。手动关闭访问会取消恢复。

## 手机端

- 在「设置 → 通知」开启「接收实时任务通知」，可以看到思考、执行、回复、等待回答或审批，以及完成、失败、停止和断线状态。授权后会同时开启后台同步，回到已配对的电脑时会沿用你的选择。「提问与审批提醒」可单独开关。
- 思考强度选择器把模型名和当前强度放在同一行，滑轨更细，保留了手指拖动和点按所需的空间。

## 安装与更新

- Windows 用户可在应用内检查更新。首次安装请下载 [Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.17/CodexLight-Setup-0.4.17-x64.exe)。
- 请将电脑和手机都更新到本版以使用完整通知功能。手机可在应用内检查更新，也可下载 [Android 安装包](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.17/codex-light-0.4.17.apk)，原有配对可继续使用。
