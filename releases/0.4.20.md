手机上的任务卡可以跟随 Codex 的当前步骤、提问和审批更新，电脑和手机也能直接在输入栏查看会话速度与上下文用量。

## 对话与任务

- 点击输入栏的「会话速度」可查看模型回复用时、工具调用用时、平均首 token 延迟和输出速度。有输出速度记录时，输入栏直接显示 tok/s。只有整轮数据时，会标为「均速」。
- 点击上下文百分比会在按钮旁展开用量明细，可以对照最近一次请求和整个对话的输入、缓存和输出 token。点击面板外即可收起，继续阅读对话。
- 图片和文件附件在输入框上方单独占一行，附件较多时可以横向滑动查看，消息和发送按钮都能看清。
- Codex 的提问卡在回答按钮旁提供「忽略」。点击即可跳过这张卡，同一对话里的其他问题仍可回答，任务进度也会继续提醒。

## 桌面与设置

- 账户页直接列出限额重置卡、到期时间和「使用」按钮。宽窗口并排显示两张卡，手机和窄窗口逐张排列。相同的赠送文案已去掉，在电脑或配对手机上都可以选中具体卡片后确认使用。

## 手机端

- 任务通知显示正在执行的操作。有计划时，可以看到已完成的步骤数和当前步骤。短暂漏掉一次后台同步时会保留运行卡，持续失联时提示状态变化。
- Codex 等待回答或审批时会更新同一张任务卡，开启提问与审批提醒后可点击直达对应请求。Android 16 及以上的状态栏实时展示由系统决定。
- 手机聊天页已移除左侧时间线，给正文留出更多空间。「设置 → 关于」现在能查看手机和配对电脑的版本及更新日志。两端版本不同时可以切换查看。

## 安装与更新

- Windows 可在应用内更新。首次安装请下载 [Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.20/CodexLight-Setup-0.4.20-x64.exe)。
- 本版包含 Android 客户端更新。手机可在应用中检查更新，也可下载 [codex-light-0.4.20.apk](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.20/codex-light-0.4.20.apk)。将电脑和手机都更新到本版即可使用完整的任务通知。
