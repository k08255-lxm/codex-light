现在可以沿时间线回看对话，从任一已完成的回答创建分支，并查看这一轮使用了多少 token。

## 对话与任务

- 对话左边的时间线会标出正在阅读的轮次，点按刻度就能跳过去。
- 每轮回答下方可复制正文、从这一轮分支到新聊天，或查看输入、缓存、输出以及各项费用。
- 侧栏会记住上次的项目顺序，载入对话后只有位置确实变化的项目才会移动。
- 附上图片后继续输入或换行，上方消息能保持在原来的阅读位置。

## 桌面与设置

- 第一次打开码舱可以选择跟随系统、浅色或深色主题，桌面工作区还可预览 Codex、Claude 和 DSH 三种界面风格。已有桌面外观设置会继续沿用。
- 打开「设置 → 引擎更新」会自动检查新版。每行显示引擎来源、安装路径和版本，npm 版 Codex CLI 可直接升级。当前正在使用该引擎时，可选择「下次启动升级」。
- 在「设置 → 配置」可查看引擎提供的模型上下文窗口，单独设置大小，或一键恢复跟随引擎。
- 用量统计可以从已有会话补回模型、用量和费用，直接显示金额。需要查看价格来源时可展开明细，列表保留账户与模型筛选。
- 各页的勾选框已统一为开关，下拉选项跟随界面主题。配对和外观设置的说明、按钮和状态之间留出了间距。
- 技能、远控和运行环境设置会自动读取操作后的状态。应用更新页会直接说明安装窗口的启动状态。

## 手机端

- 第一次打开手机端，或升级前从未设置通知时，可以选择是否开启任务提醒。选过开启或关闭的手机会沿用原选择。

## 安装与更新

- 首次安装缺少 Node.js 时，安装器会获取官方 24.x LTS 的最新补丁。已有用户可在「设置 → 关于」查看运行中的 Node.js 版本和可用更新。
- Windows 可在应用内更新。首次安装可下载 [Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.18/CodexLight-Setup-0.4.18-x64.exe)。从本版起，更新器完成后可点「立即打开应用」。
- 手机可在应用内更新，也可下载 [codex-light-0.4.18.apk](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.18/codex-light-0.4.18.apk)。原有配对可继续使用。
