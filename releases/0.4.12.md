本版修复 Windows 切回码舱后窗口无响应的问题，并新增技能管理页。

**正在使用 Windows v0.4.11？** 请直接[下载 v0.4.12 官方安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.12/CodexLight-Setup-0.4.12-x64.exe)，打开后点「检查并继续」，保存工作，再确认「安装更新」。v0.4.11 内的「安装更新」按钮会报错，重试或重新下载更新包也会出现同一提示。覆盖升级会保留对话和设置，之后可以恢复使用应用内更新。

## 桌面与设置

- 从其他应用切回码舱时，即使 Windows 通知服务响应缓慢，也可以继续点击、拖动窗口或使用托盘菜单。
- 在「设置 → Codex → 技能」中，可以搜索技能、查看来源和完整路径，分别启用或停用同名技能。已打开的对话会同步更新 `/` 菜单中的技能选项。

## 手机端

- 在手机上看到对话的最新回复后，电脑会同步清除该轮的未读标记并更新任务栏角标。其他对话的未读和待回答问题保留。

## 安装与更新

- 其他支持应用内更新的 Windows 版本可照常升级。首次安装也可使用上方的 Windows 安装器。
- 升级到本版后，后续较大的 Windows 更新包可分四段下载，下载完成后仍会校验完整文件。
- 已装 v0.4.11 的手机只需配合更新后的电脑端使用。首次安装 Android 客户端可下载 `codex-light-android-0.4.12.apk`。
