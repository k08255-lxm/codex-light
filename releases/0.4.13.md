本版可以直接导入 Codex 技能，并改进了 WSL 检测、DSH 桥接和两端的更新体验。

## 桌面与设置

- 「设置 → Codex → 技能」可导入含有 `SKILL.md` 的文件夹，原件不变，不覆盖现有技能。技能开关结果不明时，可刷新实际状态并解除锁定，不会重发旧操作。
- 首次引导或打开「连接与运行」时，会自动检测正在运行的 WSL 发行版；不会切换当前引擎。要检查已停止的发行版，可选择「完整检测 WSL」。
- 「DSH 与 MCP」区分已配置、桥接已连接和工具未就绪，显示检查时间和处理建议。「立即测试」可核对连接与工具目录，不运行任务。修复使用新版预设包的 DSH CLI 初始化问题。

## 手机端

- 安卓更新检查会跳过无需提醒的桌面版，找到最近一个适用的安卓更新。

## 安装与更新

- Windows 分段下载失败时会尝试整包下载，校验通过后才安装。
- Windows 可在应用内更新，也可[下载 Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.13/CodexLight-Setup-0.4.13-x64.exe)。若仍在 Windows v0.4.11，请直接下载此安装器覆盖升级。
- Android 可在应用内更新或下载 `codex-light-0.4.13.apk`。
