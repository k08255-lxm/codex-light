本版重做插件管理：先看已安装，直接安装、启用或停用，不用在详情里找按钮。

## 桌面与设置

- 已安装和插件目录分开显示。当前 Codex 支持时，可直接启用或停用；停用不卸载插件，也不撤销授权。
- 安装、卸载和启停只需一次确认。操作成功后刷新列表；启停状态缺失时，可单独检查该插件。
- Windows 安装向导明确说明 WSL Codex 由安装后的码舱检测。

## 安装与更新

- Windows 可在应用内更新，或[下载 Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.14/CodexLight-Setup-0.4.14-x64.exe)。若仍在 Windows v0.4.11，请直接下载安装器覆盖更新。
- Android 客户端未改动功能，不弹更新提醒。需要安装时下载 `codex-light-android-0.4.14.apk`。
