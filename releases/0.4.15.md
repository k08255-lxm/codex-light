手机现在可以在家优先用内网、出门通过公网连接同一台电脑；电脑端也可以在任务运行中更换模型。

## 对话与任务

- 新对话会记住上次选择的模型和思考强度。开启 Fast 后，模型名旁会显示小闪电。
- 任务运行中可以调整模型、思考强度和 Fast。支持此功能的引擎会在本轮后续步骤使用新设置，旧版引擎从下一轮生效。
- 选择项目时，列表顺序与对话侧栏一致，置顶和最近使用的项目更容易找到。

## 桌面与设置

- 用量页先显示已保存的统计，再从本地日志补全。重启后可以复用索引，只重读新增或变化的日志。侧栏折叠时，加载占位也会与统计卡片对齐。
- 局域网访问可以同时打开当前所有私网 IPv4 地址，优先展示以太网和 Wi-Fi 地址。也可以单独选择一张网卡。
- 在「设置 → 远程控制 → 公网隧道」可以接入已有 frp 或 Cloudflare 命名隧道。有自己的 Debian 或 Ubuntu 公网服务器时，可复制安装脚本部署转发。每台电脑使用独立子域名，同一台服务器可以接入多台电脑。

## 手机端

- 分别配对同一台电脑的内网和公网地址后，启动或重连时优先走内网，连不上再尝试已配对的公网。公网域名支持 IPv4 和 IPv6。
- 手机用电脑 ID 区分设备。两台电脑即使使用相同的内网地址，也能各自保留配对、通知和离线快照。电脑正常更新后仍沿用原 ID。

## 安装与更新

- Windows 可从应用内更新，或[下载 Windows 安装器](https://github.com/k08255-lxm/codex-light/releases/download/v0.4.15/CodexLight-Setup-0.4.15-x64.exe)覆盖升级。
- Android 可在应用内检查更新，也可下载 `codex-light-0.4.15.apk` 覆盖安装。使用公网配对和内外网自动切换时，请将手机和电脑都更新至本版。
